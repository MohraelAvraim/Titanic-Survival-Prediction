# Titanic-Survival-Prediction

## Project Overview

This project explores the famous Titanic dataset from Kaggle to analyze the factors affecting passenger survival and build machine learning models capable of predicting survival.

The project follows a complete data analysis workflow, including data cleaning, exploratory data analysis (EDA), feature engineering, model building, and evaluation.

## Dataset

Source:

Files:
